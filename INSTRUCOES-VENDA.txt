3. COMO PREPARAR PARA VENDER
═════════════════════════════════════════════════════════════════════════════════

PASSO 1: CONVERTER PARA PDF

O ebook está em arquivo TXT.
Precisa converter para PDF para ficar profissional.

Como fazer:
- Abra o arquivo no Word
- Salve como PDF
Ou
- Use www.smallpdf.com (gratuito)
- Upload do arquivo
- Download como PDF


PASSO 2: CRIAR UMA CAPA

Use o Canva para criar capa do ebook:

1. Abra Canva.com
2. Procure por "Ebook Cover"
3. Crie com:
   - Título: "Canva para Iniciantes"
   - Subtítulo: "Como criar posts, apresentações e materiais"
   - Suas cores (roxo + rosa é bom)
   - Ícones relacionados a design
   - Export como PNG

PASSO 4: CRIAR UMA PÁGINA DE VENDAS

Se vai vender em sua própria plataforma:

Usando CANVA:
1. Novo design → "Página Web"
2. Crie seções com:
   - Capa e título
   - Benefícios
   - O que inclui
   - Preço
   - Botão de compra
3. Export como HTML

Ou use WordPress + plugin de vendas (WooCommerce, Easy Digital Downloads)


PASSO 5: CONFIGURAR PAGAMENTO

Se usar Hotmart:
- Crie conta
- Faça upload do PDF
- Configure preço
- Configure comissão (Hotmart pega ~15%)
- Ative para venda
- Compartilhe link

Se usar seu próprio site:
- Integre PayPal ou Stripe
- Configure produto digital
- Teste compra
- Ativa
