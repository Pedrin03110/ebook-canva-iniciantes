# Canva para Iniciantes

Ebook completo para aprender a criar posts, apresentações e materiais visuais com Canva.

## O que você vai aprender
- Como usar o Canva do zero
- Como criar posts para redes sociais
- Como montar apresentações profissionais
- Como criar materiais de divulgação
- Design para iniciantes: fundamentos básicos
- Cores, fontes, layout e identidade visual
- Dicas para ganhar tempo e evitar erros comuns

## Arquivos
- Ebook: [ebook-canva-para-iniciantes.md](./ebook-canva-para-iniciantes.md)
- Página de vendas: [pagina-de-venda.md](./pagina-de-venda.md)

## Objetivo
Este material foi criado para ajudar iniciantes a usar o Canva de forma simples, prática e profissional, com foco em criação de conteúdos visuais para redes sociais, trabalho, estudos e negócios.

## Estrutura do ebook
- Introdução
- O que é Canva
- Primeiros passos
- Interface do Canva
- Como criar posts
- Como criar apresentações
- Como criar materiais visuais
- Design para iniciantes
- Cores e fontes
- Erros comuns
- Dicas práticas
- Conclusão

## Sugestão de uso
Você pode usar este material como base para:
- vender digitalmente
- ensinar pessoas iniciantes
- criar conteúdo de autoridade
- produzir materiais para cursos e serviços
